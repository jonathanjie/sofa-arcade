# Artwork provenance and license notes

This media pack was created for **Sofa Arcade / Odd Laws Society** at the
repository owner's request on 20 November 2026.

| Material | Origin |
| --- | --- |
| Building and character raster illustrations | Original images generated with OpenAI's built-in image-generation tool for this assignment |
| Style and character identity references | Existing repository files `public/assets/characters.png` and `public/assets/sofa-room.png`, inspected before generation; their original files and attribution were retained |
| Law emblems, guild marks, and props | Original SVG artwork authored for this game |
| Names and catalog mapping | The repository's original Odd Laws Society v0.2 design document |
| Music and effect cues | Original authored event data in `ui/media/odd-laws-society/score.mjs` and `effects.mjs`; no recordings or sample packs were used |

No commercial board-game art, stock illustration, external icon set, third-party
music recording, or downloadable font is included in the pack. This notice
records provenance and does not introduce a new license for the repository or
replace the owner's existing distribution terms.

Generation prompts, reference hashes, optimization methods, and output records
are retained in `sources/` and the `ui/media/odd-laws-society/provenance-*.md`
notes. The shipped raster files are optimized game assets, not the oversized
generation intermediates. SVG files are their own editable source.

Development tooling uses separately licensed npm packages; their versions,
integrity hashes, and package licenses are recorded in the isolated
`ui/media/odd-laws-society/package-lock.json`. They are not game runtime assets.
